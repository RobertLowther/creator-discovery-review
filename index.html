Creator Discovery Engine

Reviewer documentation for an internal command-line tool that runs on the operator’s computer. This site describes the tool and its data practices.

What the tool does

The tool searches public YouTube videos on practical and educational topics to identify creators for potential digital-product partnerships. It uses the YouTube Data API v3 to retrieve public channel and upload metadata, saves records in a local SQLite database, and exports CSV reports for internal review.

How to review the workflow

  1. Run the discovery command to collect public video search results and channel details.
  2. Inspect the stored upload records and request totals.
  3. Export CSV reports and inspect the source channel links and search provenance.

The audit submission provides a separate screencast of this local workflow. No login or public endpoint is available.

Requested analytics

The application seeks approval to calculate median and mean video views, upload frequency, and a preliminary candidate ranking. Live collection currently uses raw API data. The analytics workflow can be demonstrated with synthetic test data.
