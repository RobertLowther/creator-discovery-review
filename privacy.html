Project overview · Privacy policy and terms

Privacy policy and terms

Creator Discovery Engine is a local command-line tool for internal creator research. It uses YouTube API Services. Google processes requests according to the Google Privacy Policy.

Data the tool uses

The tool sends search terms, channel and video identifiers, and an API key to Google to retrieve public search results, channel and upload metadata, and public statistics such as view counts and subscriber counts. It uses an API key for public lookups and does not request YouTube account access or sign-in credentials.

Storage and access

The tool writes search provenance, public metadata, and request logs to a local SQLite database. Operators can export CSV reports for internal review. This public documentation site does not display those records. GitHub hosts the documentation and may process visits as described in the GitHub Privacy Statement.

Retention and deletion

The tool checks for expired API data on each run and purges cached API records after 30 days. Operators should run the purge command regularly and remove expired CSV exports and backups separately. To remove an entire local collection, close the tool and delete its database, exports, and any copies. For a privacy question or deletion request, contact the operator using the project’s GitHub issue tracker. Include only the public channel or video link in a public issue.
